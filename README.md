# AI Skin Lesion Classifier

## Model Download

The trained model is not included in this repository due to file size limits.

Download it from Google Drive:
https://drive.google.com/drive/folders/1fc_Jj7kvep5uD12SAb06htHbG40yZOEW?usp=sharing

After downloading, place the file here:

backend/model_mc.pth

Only the model file is required. Do not download or include any other files.

This project is a web-based AI system that classifies dermoscopic skin images using a ResNet18 model and provides Grad-CAM visual explanations.

## Setup

1. Install dependencies:
pip install -r requirements.txt

2. Run the app:
python app.py

3. Open in browser:
http://127.0.0.1:5000

## Notes

Model file (model_mc.pth) and dataset are not included due to size.
